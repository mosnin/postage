# Project Brief

## App Name
PostSyncer

## Tagline
Create Once. Share Everywhere.

## One-Line Description
Schedule, publish, and analyze content across 11 social media platforms with AI-powered creation tools and team collaboration — all from one dashboard.

## Value Proposition
PostSyncer eliminates the chaos of managing multiple social media accounts by giving teams a single place to plan, create, and publish content with AI assistance, track performance, and respond to audience engagement.

## Core User Journey
1. User connects their social accounts (OAuth per platform)
2. User composes a post (text, images, video) in the editor
3. User selects which platforms to publish to
4. User schedules the post or adds it to a queue
5. Post publishes automatically at the scheduled time
6. User monitors engagement in the unified inbox and analytics

## Key Differentiators
- Support for 11 platforms including newer ones (Threads, Bluesky, Mastodon)
- AI Content Agent that generates posts from URLs, PDFs, or free text
- Unlimited team members on all paid plans
- Built-in MCP integration for AI assistant workflows (Claude, Cursor)
- Unified comment inbox across all platforms

## Success Metrics (V1)
- Users can connect at least one social account and schedule a post within 5 minutes of signup
- Dashboard loads in <2 seconds
- All 3 pricing tiers functional with Stripe
- Mobile-responsive on all core pages
- Zero data leakage between workspaces
